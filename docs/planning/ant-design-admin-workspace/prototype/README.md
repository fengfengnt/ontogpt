# OntoGPT 管理台设计草图

状态：已制作，等待视觉评审；具体配色与技术迁移路线尚未确认。

当前为 v0.3 草图：整行头部包含 logo、平台名称及右侧主题下拉按钮；下方左侧为可手动收缩成图标的菜单，右侧为 tab 工作区。整体高度适配浏览器视口，页面外层不滚动；菜单和各 tab 内容分别独立滚动，头部、tab 标签栏及底部用户区保持固定。支持浅色商务蓝、暗黑深蓝灰、绿色低饱和灰绿三种主题。使用 Ant Design 6.6.7、React 19.3.1，所有资料、知识与操作均为本地模拟。产品管理台及其依赖未修改。

## 打开

先按下方命令构建，再用浏览器打开同目录生成的 `workspace-prototype.html`。生成文件包含所需脚本和样式，无须启动后端；该编译产物不纳入版本管理。

首次查看或修改草图时，在本目录执行：

```powershell
npm.cmd ci --no-audit --no-fund
npm.cmd run build
node self-check.mjs
```

`app.jsx`、`style.css`、`workspace.mjs` 为可编辑源文件。预览服务的会话与依赖目录已由本目录的 `.gitignore` 排除。

## 体验顺序

1. 从“本体画布”打开“新增条目”，填写名称、描述、证据。
2. 通过头部“主题”按钮下拉切换三种主题，或点击侧栏按钮收缩／展开菜单，再回到该表单，检查内容是否保留。
3. 点击表单 tab 的关闭按钮，选择“继续编辑”或“放弃修改并关闭”。
4. 关闭“本体画布”来源 tab，再提交表单；来源页会重开，显示刷新次数和待发布条目。
5. 保持另一份资料草稿未提交，重复上述提交操作，检查其他 tab 内容不变。
6. 点击右上角问号，可切换预览身份，或模拟下一次提交失败。
7. 关闭最后一个 tab，检查角色默认入口；刷新浏览器，检查仅主题偏好保留。
8. 缩小浏览器展示区域高度，分别滚动长表单和菜单；检查页面、头部、tab 标签栏及底部用户区保持原位。

## 范围限制

- 树展示采用真实 Ant Design Tree；树的节点增删和版本冲突流程留待正式迁移设计。
- 本体关系画布为 SVG 示意，未接入 Cytoscape 的布局、缩放和真实关系数据。
- 表单提交、提取、审核及 Schema 草案均为内存模拟；未连接后端、数据库、真实权限或模型，未执行正式发布。
- 只在浏览器保存带草图命名空间的主题偏好。刷新后清空 tab、草稿和模拟业务变更。
- 完整三主题视觉对比和正式管理台迁移仍需根据用户反馈继续设计。
