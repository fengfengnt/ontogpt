# OntoGPT Ant Design 管理台与多标签工作台决策地图

Labels: wayfinder:map

## Destination

形成可供评审并据此制定实施计划的完整设计：将 `D:\Code\ontogpt` 中采购本体知识服务的整个管理台全面迁移到 Ant Design，支持保留页面编辑状态的多标签工作台，以及浅色、暗黑、绿色护眼三种主题。

本地图负责确定设计决策；产品代码的实施须在设计评审通过后另行规划。

## Notes

- 使用 brainstorming、wayfinder；一次讨论集中处理一个决策，未确认的提议不能记作用户决定。
- 本地图使用本地 Markdown tracker；本轮设计文档和决策材料集中放在本目录，与既有采购本体产品决策地图保持独立，并按需引用其业务边界。
- 用户已明确更正目标项目为 `D:\Code\ontogpt`；该需求不适用于 `new-api`，也不迁移原目标项目的框架假设、业务模型或仓库专属规则。
- 改造入口为 `frontend/procurement-ontology/` 的采购本体管理台，覆盖平台和企业侧已有管理能力；`src/ontogpt/webapp/` 的原有抽取演示保持独立。
- 用户已明确范围为整个管理台、全部组件迁移；不能将只改外壳或只改用户管理样板作为最终交付。
- 界面面向 toB，采用商务风格；三级等层级数据应使用合适的树形控件。
- 点击菜单打开对应 tab；已有对应 tab 时直接激活，不能重复创建该菜单页面。
- 切换菜单或 tab 时保留页面中未提交的编辑内容；刷新页面后不保留，不做草稿持久化。
- 新增用户等较大的功能表单可打开独立 tab，使用完整内容区。
- “新增用户”是用户说明功能 tab 的例子，不据此增加 OntoGPT 尚无的账号管理业务；实际功能应映射到本项目现有管理操作。
- 默认第一个 tab 是第一个菜单功能，关闭最后一个 tab 后重新打开默认入口。原请求用“概览”举例；OntoGPT 当前不同角色的首菜单不同，具体默认入口由本项目的决策票据明确。
- 菜单、活动 tab 和面包屑同步；功能 tab 高亮最近的所属菜单，面包屑追加功能名称。
- 增加浅色、暗黑、绿色基调护眼三种主题。
- 保留既有业务能力及本地修改；界面重构不能放宽平台/企业隔离、候选审核、版本发布和 schema 显式启用的业务约束。三级分类树沿用“采购负责类 → 一级品类 → 二级品类”的项目术语。
- 当前管理台是 React、TypeScript、Vite 和 Cytoscape；菜单由 App 本地状态控制，尚无路由库、多标签工作区和主题切换机制；三级树使用手写结构。原目标项目的 Base UI/shadcn、TanStack Router、Zustand 和已有主题保存机制均不是本项目事实。
- 源码核对不是浏览器运行验证；本轮迁移的是需求与决策材料，尚未实施产品代码。
