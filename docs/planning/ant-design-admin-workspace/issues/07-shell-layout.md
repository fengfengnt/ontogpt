## Question

头部、菜单和 tab 工作区如何布局，主题入口和菜单收缩如何呈现？

## Answer

用户明确要求：上方整行作为头部，包含 logo、平台名称及主题按钮；主题通过下拉菜单选择“浅色、暗黑、护眼”。头部下方左侧为菜单，可收缩为仅图标；右侧为 tab 页工作区。

- 头部横跨页面全宽，logo 和平台名称位于头部左侧，主题按钮位于右侧。
- 菜单与 tab 工作区位于同一个下方内容行，菜单收缩后工作区使用释放的宽度。
- 侧栏提供手动展开／收起按钮；收缩后保留菜单图标、可访问名称和悬停提示。
- 菜单收缩与主题切换保留已有 tab、活动页面及未提交表单。
- 整体高度随浏览器可视区域调整，页面外层不出现滚动条；头部和 tab 标签栏保持固定，仅各 tab 的内容区独立滚动。
- 左侧菜单项较多或窗口较矮时，菜单区域单独滚动；底部用户区位于菜单滚动区域之外，始终固定在侧栏底部。
- 菜单收缩为图标后，侧栏底部仍保留用户头像；展开后恢复完整用户信息。

### 独立滚动复查

v0.3 草图已落实上述滚动要求。浏览器在 1280×540 可视区域中实际滚动长表单与菜单：文档高度和滚动高度均为 540px、文档滚动位置始终为 0；长表单可到达底部保存按钮，菜单独立滚动时 tab 内容位置不变，用户区底部始终为 540px。切换 tab 后草稿及该 tab 的滚动位置保留。

恢复浏览器正常展示区域（约 666×764）后，文档滚动高度仍等于视口高度，用户区继续固定在底部。菜单收缩后保留底部头像。参见独立滚动检查截图（本地历史截图 `preview-independent-scroll.png`，不随源码入库）。
