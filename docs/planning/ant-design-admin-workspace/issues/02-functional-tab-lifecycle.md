## Question

同一功能是否允许同时打开多个实例，例如两个“新增用户”，以及编辑不同用户？表单提交成功后如何返回并刷新来源 tab，来源 tab 已关闭时如何处理？

菜单页面重复点击直接激活已有 tab、最后一个 tab 关闭后打开默认入口，均为已明确需求；原请求的“概览”例子在 OntoGPT 中的具体映射见[默认标签与角色菜单的回落入口](06-default-workspace-entry.md)。

## Comments

### 已确认：功能 tab 的实例规则

针对以下建议，用户答复“采用”：

- 同一新增功能只打开一个 tab；重复点击激活已有 tab，保留其中的草稿。
- 编辑不同记录可以分别打开 tab。
- 重复编辑同一条记录时，激活已有编辑 tab，不创建重复实例。

### 已确认：提交后的返回与刷新

用户原话：“是。 成功关闭表单tab后，回到产生这个表单的功能按键的标签页，即使它被关闭了也打开，并且刷新此页（因为可能是列表页，需要显示此新增的数据）”。

## Answer

- 同一新增功能只保留一个 tab，重复点击激活已有草稿。
- 编辑不同记录可以分别打开 tab；同一记录重复编辑复用已有 tab。
- 来源 tab 指承载发起该表单的功能按钮的标签页，不能直接用所属菜单页替代这一关系。
- 提交成功后关闭表单 tab，激活并刷新来源 tab；来源 tab 已关闭时，重新打开该来源页面后刷新。
- 刷新作用于来源 tab 的数据，保留其他 tab 的编辑状态。
- 提交失败时保留表单 tab 和已填写内容，并显示错误信息。
