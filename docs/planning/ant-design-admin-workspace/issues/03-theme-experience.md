## Question

浅色、暗黑和绿色护眼三种主题的实际外观、默认主题和切换入口如何确定？主题偏好是否在当前浏览器保存？OntoGPT 当前没有主题切换机制，不能沿用原目标项目的“跟随系统”或颜色预设假设。主题需要在布局、表格、表单、弹层及本体画布中保持一致。

视觉草图应作为讨论材料，不能作为已批准的产品实现。

## Comments

用户将本需求的目标项目更正为 `D:\Code\ontogpt`。已确认下述主题行为，并答复“制作”，授权制作独立可点击草图；具体配色和视觉效果仍待评审，不表示已批准产品代码实施。

## 已确认的主题行为

用户对默认主题、切换入口、浏览器记忆及编辑状态保留的建议答复：“采用”。

- 默认使用浅色主题。
- 在整行头部的右侧提供“主题”按钮，通过下拉菜单选择“浅色、暗黑、护眼”；入口形式按用户本轮布局调整更新。
- 当前浏览器记住主题选择，刷新和下次打开时沿用；仅保存主题偏好，未提交表单仍按既定规则在刷新后丢弃。
- 切换主题即时生效并保留所有已打开 tab 的编辑内容，覆盖基础控件、弹层及本体画布。

## 尚待确认
