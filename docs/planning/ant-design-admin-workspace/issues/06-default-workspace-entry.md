# 默认标签与角色菜单的回落入口

Type: grilling
Status: resolved
Blocked by: none
Map: [OntoGPT Ant Design 管理台与多标签工作台决策地图](../map.md)

## Question

OntoGPT 当前没有统一的“概览”页面：平台管理员首菜单是“通用本体”，企业管理员是“资料与提取”，只读用户是“本体画布”。首次进入以及最后一个 tab 被关闭时，是否统一按当前角色第一个有权限的菜单作为默认入口？

原请求把“概览”作为第一个菜单功能的例子。不能将原目标项目的具体菜单名称直接当作本项目已有功能。

## Answer

用户确认：“按角色首个有权限菜单（推荐）”。

- 首次进入工作区以及关闭最后一个 tab 后，打开当前角色第一个有权限的菜单。
- 按当前菜单顺序，平台管理员打开“通用本体”，企业管理员打开“资料与提取”，只读用户打开“本体画布”。
- 本轮不新增统一“概览”页面；入口随当前角色的可用菜单确定。
- 关闭含未提交修改的最后一个 tab 时，仍先确认放弃；取消关闭则保留原 tab，确认关闭后再打开默认入口。
