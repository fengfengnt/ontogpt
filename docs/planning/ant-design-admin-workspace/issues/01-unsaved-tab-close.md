# 未提交内容的标签关闭规则

Type: grilling
Status: resolved
Blocked by: none
Map: [OntoGPT Ant Design 管理台与多标签工作台决策地图](../map.md)

## Question

用户主动关闭含未提交内容的 tab 时，是否确认放弃修改？取消关闭与确认关闭后各应发生什么？此决策不改变已确认的“切换保留、刷新丢弃”规则。

## Answer

用户确认：“需要确认是否放弃修改”。

- 主动关闭含未提交修改的 tab 时，先显示放弃修改确认框。
- 取消：不关闭 tab，继续保留当前编辑内容。
- 确认放弃：关闭该 tab，丢弃该页未提交内容，不自动提交。
- 若关闭的是最后一个 tab，确认放弃并关闭后再打开默认入口；原请求用“概览”举例，项目更正后的具体入口见[默认标签与角色菜单的回落入口](06-default-workspace-entry.md)。
- 切换菜单或 tab 继续保留内容；刷新页面后不保留，均沿用已明确需求。
