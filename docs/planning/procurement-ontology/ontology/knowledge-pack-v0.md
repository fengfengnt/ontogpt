# 二级品类知识包与企业约束规则：最小本体结构（设计稿）

状态：首版数据结构规格，尚未实现；本文件描述逻辑模型，首版权威库见[Jena 选型依据](../research/jena-fuseki-authoritative-store-v0.md)，发布前校验见[词汇与 SHACL 设计稿](./rdf-vocabulary-shacl-v0.md)。决策见[知识包结构票据](../issues/22-define-knowledge-pack-structure.md)。

## 结构与归属

| 本体对象 | 最少内容 | 关系 |
| --- | --- | --- |
| `KnowledgePackage` | 稳定 ID、所属甲方、关联二级品类 ID、名称、说明、来源、所在企业本体版本 | 一个已发布甲方二级品类至多关联一个当前知识包，也可暂缺；历史版本保留 |
| `CollectionField` | 稳定 ID、名称与含义、数据类型、单位、必填说明、可用默认建议、来源 | 知识包包含多项；Agent 用于补问，本次取值归外部采购系统 |
| `SupplierConditionTemplate` | 稳定 ID、条件原文与说明、适用阶段、默认必须/加分属性、默认分值与评分细则、来源 | 知识包包含多项；是本次条件的建议来源，不等于本次已确认条件 |
| `JudgmentInstruction` | 稳定 ID、对应条件、供 LLM 使用的判定说明、可用的乙方本体事实/本次声明/材料类型、结果与理由要求、来源 | 条件模板引用；不把一段知识包描述当作不可追溯的整体指令 |
| `EnterpriseConstraintRule` | 稳定 ID、约束原文与说明、硬约束标记、适用范围、生效时间、来源、所在企业本体版本 | 属于甲方企业本体，不归某个二级品类独占；知识包可引用以便展示 |

上述条目保留稳定 ID、来源原文或编辑记录、发布它的企业本体版本。修改条目产生新本体版本，旧版本不可改；本次采购条件快照引用它采用的条目和版本。本次乙方能力、声明及项目材料不放进甲方知识包。

## 规则生效与判定

1. **普通条目不隐式继承**：采购负责类或一级品类下的普通说明、字段和条件，不因树的父子关系自动套用到二级品类。要复用，知识包显式引用已发布条目。
2. **企业硬约束按范围生效**：企业本体发布的`EnterpriseConstraintRule`声明适用品类或采购场景及时间。本工程对本次采购查找适用规则并逐条判断；知识包中的引用用于 Agent 展示和审计，漏写引用不使适用的硬约束失效。未发布候选没有企业硬约束效力。本次采购员输入可覆盖知识包默认建议，不能覆盖适用的已发布硬约束。
3. **业务判断交 LLM**：包括条件适用性、客观数值条件、乙方满足情况和企业硬约束是否冲突。每次输入相关规则原文、采购员确认值、乙方本体及本次声明/材料；输出逐条结论、理由、引用、模型/提示配置版本。无需为客观条件另建可执行比较式。若已发布硬约束是否冲突无法判断，返回`需求数据未齐备/待澄清`，请采购员补充后重判。
4. **基础校验由程序执行**：认证授权、必需 ID 与字段是否存在、声明的数据类型与单位格式、引用的本体/分类版本是否有效、分值与权重合计等结构校验不交给 LLM。它们不决定采购业务条件是否满足。
5. **本次条件保持独立**：外部系统持有采购员确认的条件原文、取值、必须/加分标记、权重和版本。知识包未定义的新条件可立即作为本次 LLM 输入；本工程自动生成甲方待确认候选，确认发布后才变成可复用条目。
6. **缺少知识包仍可形成本次需求**：LLM 可给出临时字段与条件建议，采购员逐项确认后用于本次采购；本工程在整份条件快照确认后自动把新知识入待确认候选，未发布前明确标记为临时内容。详见[采购对话草案 API 契约](../api/procurement-draft-v0.md)。

## 以“采购 100 台电脑”为例

- 甲方树确定`IT与通讯 → 办公设备 → 电脑(台式机/笔记本)`。该二级品类引用一个已发布知识包。
- 知识包中的`CollectionField`告诉 Agent 至少收集数量、单位，以及本企业实际设定为必填的其他字段；`100 台`是本次值，外部系统保存。
- 知识包中的`SupplierConditionTemplate`可以建议“营业执照经营范围包括计算机销售”，关联`JudgmentInstruction`。是否设为本次必须项由采购员在外部条件快照中确认；乙方可逐项作诚信声明，LLM 结合本次声明判断并标明自述来源。
- 若企业另有已发布的“单台电脑采购价不得超过某上限”硬约束，它作为`EnterpriseConstraintRule`独立存在并按适用范围判断；即使知识包未列出引用，也不能被本次采购员输入绕开。这里的价格上限仅为**结构示例**，不表示模拟笔记本案例的 9,500 元目标已被改为否决规则。
- 采购员新提“五年维保”即使不在知识包，也由 LLM 对本次乙方响应判断；该新条件入甲方待确认候选，乙方新承诺另入乙方待确认候选。

## 发布前结构校验

发布批次至少校验：关联的企业与二级品类节点已在企业分类树中发布；被引用的条目已发布或在同批采纳；条件模板的判定说明可追溯；硬约束有适用范围、生效时间和原文来源；同一适用期互斥的已确认规则已处理。若二级品类是新节点，先发布树版本，再发布引用它的知识包，见[候选审核与发布规则](./publication-rules-v0.md)。校验只保证结构完整和冲突显式处理，不宣称 LLM 的业务判断必然正确。
