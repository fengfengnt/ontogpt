# “电脑(台式机/笔记本)”二级品类知识包候选 V0：笔记本部分

状态：**待企业管理员确认的建模样本**，尚非已发布企业本体。来源是模拟采购案例（外部原始材料 `笔记本电脑采购全过程案例.md`，未纳入仓库）（SHA-256 `AF2A287082514526FF4413900EFAE65AF99B4C10827DB619CAECB290E8F5ED45`）；下文 `Lx` 为原文件行号。`案例`表示原文可定位，`用户修订`表示此前对本模拟案例的明确补充，`常识建议`表示本次归纳、没有企业原文依据，发布前须由企业人员确认。

## 归属与边界

关联甲方三级路径：`IT与通讯 → 办公设备 → 电脑(台式机/笔记本)`；用户已确认“笔记本电脑”属于这个二级品类，不另建第四层节点。知识包以该二级品类为主体，当前从案例填充的是**设备类型=办公笔记本**的条目；笔记本专有字段与条件应在条目上标明适用设备类型，不自动套给台式机。最终节点 ID 以甲方发布的分类树为准。

知识包保存**问题、字段定义、条件模板、术语区别和来源**。本次采购的数量、预算、品牌、配置门槛、截止时间、必须/加分性质及评分权重由外部采购系统记录。案例中“100 台”“500 万元注册资本”“16GB 内存”等只列作**本次示例值**，不作为所有企业或所有笔记本采购的默认硬约束。具体业务满足判断属于第二阶段；第一阶段只供 Agent 查询与引用。

为防止误用，本稿所有条目初始适用范围均标为`设备类型=办公笔记本`；管理员可在审核时把确实共用的条目扩展到台式机。本知识包尚缺台式机专属知识，不用笔记本内容代填。

## 3. 术语与回答依据

| ID | 知识点 | 来源性质 |
| --- | --- | --- |
| `N01` | “原厂上门保修”“经销商延保”“送修”是不同服务方式；年限相同不代表服务相同。 | 案例 L76、L248-L251 |
