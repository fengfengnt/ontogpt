## Question

采购需求拆分到多条分类路径后，乙方如何选择参与部分需求；单供应商采购时怎样验证其覆盖全部拆分需求？哪些条件可由分类层级推得，哪些必须来自供应商已确认的能力和资质事实？结果需展示什么命中、不满足、未知和证据，怎样避免把“没有资料”误判为“不具备”或“已合规”？

## Answer

- 采购需求可拆成多个采购项，例如 100 台电脑与 100 件工服。允许多供应商时，乙方可只申请自己覆盖的采购项；要求单一供应商时，乙方须覆盖全部采购项，并满足其必须项，才可初步入围。
- 品类覆盖由系统比较甲方采购项与乙方已确认能力所引用的完整分类路径及描述，自动判断跨企业语义匹配；不明确时暂不算覆盖，见[界定分类树的来源与维护责任](./08-define-taxonomy-source.md)。品类覆盖不能推出品牌、单价、维保或案例等具体条件也满足。每项条件要分别关联乙方已确认事实或本次提交的证据；**客观、证据可核验的必须项可按甲方已发布政策机器判定，主观项或证据争议由甲方有业务审核权限的人确认**。乙方自述或仅有品类归属不能自动通过。自动入围政策与外部系统职责见[界定供应商 Agent 接收需求到邀请入围的业务契约](./16-define-supplier-agent-shortlist-flow.md)。
- 条件只有“必须项”和“加分项”两种判定作用；“选择性满足项”按加分项处理，不另设最低满足数量。必须项是否通过与各条件得分分开；必须项也可计分，具体门槛、权重计算和跨采购项汇总由[界定评标权重与分数汇总](./10-define-scoring.md)决定。
- 邀请投标前，必须项缺资料显示“待补资料”，乙方暂不初步入围，可在甲方设定的**入围截止**前补齐。截止仍缺资料按不满足处理。缺少加分项资料不阻止入围，但不能获得该项加分。
- 甲乙双方逐条件查看“满足 / 不满足 / 待补资料 / 待甲方核验”、采用的分类路径、相关本体内容及来源；数值评分明细的开放时点见[界定评标权重与分数汇总](./10-define-scoring.md)。有权限的专家还可查看本体版本、证据和判定过程，用于审计和排错。本工程返回判定，不记录正式入围；外部系统可在甲方预授权政策下自动邀请，或交甲方审核人处理。
