## Question

在笔记本资格预审中，哪些乙方事实应先由乙方确认并发布在自己的本体中，哪些项目专属证据应由外部系统随本次判定传入？证据输入怎样携带来源、时效与本次披露授权，使本工程能在不接管采购业务台账的前提下按知识包逐项判定？

## Answer

- 可复用的乙方资格与能力事实由乙方确认并发布在本企业本体中，包括注册资本、成立日期、授权品牌、上海服务团队和过往项目案例等；针对本采购项目的原厂授权函等一次性材料，由外部系统随本次响应和判定请求传入。乙方本体事实及本次材料都须关联来源，品类覆盖仍单独判定。
- 为支持 LLM 查找相关证据，本工程接收权限范围内可检索的文档文本、来源与版本，返回命中的原文片段、关联条件和理由；原始 PDF/图片由外部系统保管。本工程只保留必要判定审计，不把附件或本次响应当作本体事实自动发布。
- 每次判定明确外部采购项目 ID、判定时间与资格预审阶段。证据记录有效期或适用时间、关联品牌和项目；本工程按这些范围检查，缺少必要信息时返回`待乙方补资料`，不能仅因文本相似就判满足。入围截止后仍缺资料按既有规则判不满足。
- [笔记本案例数据收集清单](../cases/laptop-prequalification-data-request.md)给出可交付给同事的最小字段；模拟复盘未附多数供应商的逐项证据，不能据其结论倒填本体事实。
