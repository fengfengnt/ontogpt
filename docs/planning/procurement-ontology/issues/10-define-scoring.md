## Question

每个采购项内的条件权重如何计分、是否要求合计为 100？必须项通过后是否也计分？乙方参与多个采购项或甲方要求单一供应商时，怎样形成可比较的总分，并展示各项贡献和未得分原因？

## Answer

- 每个采购项独立按 **100 分**设计；各可计分条件的满分合计须为 100，发布前校验。必须项也可计分，例如 SLA 满分 5 分。甲方按每项必须项预设最低通过分，计分必须项得 0 分必定不通过；若某必须项只作门槛、满分为 0，则单独按“满足 / 不满足”判断。高总分不能抵消任何必须项未通过。
- 甲方在细则中预设评分档位或区间。邀请前，**客观且证据可核验**的必须项可按已发布细则机器给入围初评分；主观项、材料争议和投标后的评标最终分仍由甲方有评审权限的人依据证据评分并记录理由。缺少加分项证据得 0 分；必须项缺资料按[界定可解释匹配的判定与结果](./07-define-explainable-matching.md)处理。自动入围只适用[供应商 Agent 准入契约](./16-define-supplier-agent-shortlist-flow.md)规定的预授权场景。
- 首次邀请乙方前锁定条件、各条件满分、必须项门槛、采购项汇总权重和评分细则。邀请前按已有证据给**入围初评分**；投标截止后按同一细则及投标材料给**评标最终分**。最终分若低于任一必须项门槛，该投标无效；两次分数、依据和所用细则版本均留存。
- 甲方要求单一供应商时，乙方须覆盖并通过全部采购项；甲方给每个采购项设置汇总权重，合计 100%，以各采购项的 100 分制最终得分乘该权重后求和。允许多供应商时，按采购项分别比较参与该项的乙方，不以参与项目数不同的总分混排。
- 首次邀请后若确需修改评分规则，发布新版本并通知所有已受邀乙方，给同等补充或重提机会；全部投标按同一新版细则重评，旧分数与版本保留供审计。
- 评标中甲方评审人和授权专家可查看全部逐条件得分、未得分原因、证据及汇总过程。结果确定后，乙方可查看自己的明细，不查看其他乙方资料。得分用于排序与解释，不自动决定中标；最终由甲方有选定供应商权限的人依企业流程决定，未选最高分时记录理由。
