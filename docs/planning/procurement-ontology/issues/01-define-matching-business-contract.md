# 界定首版采购需求与供应商能力的业务契约

Type: grilling
Status: resolved

## Question

首版中，甲方一次采购需求、乙方一项可供能力各由哪些业务事实组成？已确定大需求可拆为多个 `采购负责类 → 一级品类 → 二级品类` 路径，乙方可选择参与部分细分需求，单供应商采购要求乙方覆盖全部拆分需求；还需决定拆分单元、覆盖口径、必备条件与排序条件，以及“初步入围”对双方的含义。用品牌策划、直播服务和跨品类供应商案例检验。

## Answer

- 一次甲方采购需求可拆为多个采购项。每个采购项指向一条完整的 `采购负责类 → 一级品类 → 二级品类` 路径，并单独定义本次采购的准入条件集合；分类节点本身不固定这些条件。例：电脑项可要求品牌、单价、维保；品牌创意与策划项可要求主导设计品牌数量、Logo 制作、品牌宣传方案。
- 每项条件记录是否为必须项及评分权重。**必须项是否满足**与**后续评标分数**分别判定；权重用于后续评分，不以总分替代必须项判断。“选择性满足项”按加分项处理，具体计分规则留给[界定评标权重与分数汇总](./10-define-scoring.md)。
- 乙方按自己的已确认能力选择参与一个或多个采购项。邀请投标前，甲方通过本工程的判定及必要的人工核验，核对乙方对拟参与采购项的二级品类覆盖和必须项；预授权自动入围条件见[供应商 Agent 准入契约](./16-define-supplier-agent-shortlist-flow.md)。若甲方要求单一供应商，则乙方须覆盖该需求的**全部**拆分采购项及其必须项，才能初步入围；否则可就所覆盖的采购项入围。
- “初步入围”仅指甲方允许乙方进入本次投标/竞标环节，不表示中标、签约或开始履约。邀请前必须项的证据、缺失状态和入围截止规则见[界定可解释匹配的判定与结果](./07-define-explainable-matching.md)。
