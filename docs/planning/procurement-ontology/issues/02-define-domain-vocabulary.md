# 界定采购负责类、品类、服务能力与甲乙方本体边界

Type: grilling
Status: resolved

## Question

“采购负责类”“品类”“服务能力”“企业经营范围”分别指什么，彼此是分类、包含、提供、适用还是别的关系？甲方本体与乙方本体是两套独立模型，还是同一核心语义上的两种企业视图？如何表达一个乙方跨采购负责类、跨品类经营，以及一个品类被多个采购负责类使用？

## Answer

- 分类结构是严格的三级树：`采购负责类 → 一级品类 → 二级品类`。每棵企业树中，每个一级品类只属于一个采购负责类，每个二级品类只属于一个一级品类；同一品类不跨采购负责类复用。平台通用树作为模板，甲乙方各自维护企业树；跨企业语义匹配见[界定分类树的来源与维护责任](./08-define-taxonomy-source.md)。采购需求使用完整路径定位所需的二级品类。是否另设物料与服务的分类属性，留到需求契约票据决定。
- “品牌创意与策划”是分类节点，不是某个乙方的能力。乙方另有“可提供服务/物料”的能力记录，每条记录指向一个二级品类；乙方可以有多条记录。乙方的采购负责类及一级品类归属由**已确认**的二级品类能力向上推得，因此可跨采购负责类、跨品类经营；仅仅归属某采购负责类不表示具备其下全部品类能力。
- 甲方本体与乙方本体使用同一核心语义，是各企业自己的本体视图；各自的分类树可有不同节点，由系统比较完整路径及描述判断语义是否匹配。甲方视图包含甲方信息、采购流程、参与竞标或履约的乙方及相关事项；乙方视图包含自身能力、参与竞标的甲方，以及合同交付进展。双方所见对方信息的同步、授权与边界仍需单独决定。
- 示例中，“市场营销与传播 → 创意与品牌 → 品牌创意与策划”和“市场营销与传播 → 媒介管理 → 媒介策略与服务 / 直播服务”是不同叶节点路径；“市场营销与传播”在这里是采购负责类，“直播服务”是另一项二级品类。
- 一个大需求可关联多条完整分类路径；乙方可选择参与其中一条或多条。单供应商采购时，只有覆盖全部拆分需求的乙方才进入初步入围。拆分、覆盖与后续入围的精确定义留给业务契约和匹配票据。
