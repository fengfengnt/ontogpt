## Question

从多家企业资料观察到的共性，达到什么证据、授权和脱敏条件才可形成通用候选？谁审核发布，如何处理相似但不等价的术语，以及错误发布后的撤回和影响范围？

## Answer

- **首版例外**：从一家甲方和一家乙方的已确认本体总结首版通用基线，经平台人工审核后发布；明确记录它只来自两家试点，不声称已满足后续“三家”共性门槛。
- **后续新增**：同类业务中三家独立企业各有已确认的语义相似内容时，形成共性候选，进入平台“本体审核”列表。例如三家甲方都确认采购职责包含“审核合同”。三家是企业数，不是同一家企业内的三条记录；相似只触发审核，不自动判断等价或发布。
- 平台系统管理员审核候选、编辑并发布通用基线，记录操作人和基线版本。企业管理员只管理或提交本企业内容，不能直接修改通用基线。相似但不等价的术语不强行合并，由审核人补充说明文字，解释各自含义与差别。
- 对企业可见的通用定义不包含来源企业名称、合同等具体业务数据；审核后台保留受权限保护的来源引用和确认依据。提升通用内容不公开原始企业资料。
- 编辑或删除通用内容产生新的基线版本，仅影响该版本及以后采用它的企业；已固定引用旧版的企业本体和历史记录不被自动改写。具体升级影响与迁移交由[界定通用基线升级的影响评估与迁移](./09-define-baseline-upgrade.md)。
