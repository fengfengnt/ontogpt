# 笔记本模拟案例：资格预审数据收集清单

用途：给数据收集同事准备**建模与接口联调样本**；不是要求提供真实企业隐私数据，也不把模拟复盘（外部原始材料 `笔记本电脑采购全过程案例.md`，未纳入仓库）的结论倒填为供应商事实。依据见[案例映射](./PRO-IT-2026-014-review.md)、[乙方事实和证据输入决策](../issues/20-define-prequalification-evidence-input.md)及后续[诚信声明与 API 决策](../issues/21-define-prequalification-api-contract.md)。

## 甲方本次采购项

| 必需内容 | 本案例已知 | 尚需提供或确认 |
| --- | --- | --- |
| 外部采购项目 ID、判定阶段与时间、入围截止时间 | `PRO-IT-2026-014`；阶段为资格预审；文档只写报名截止 2026-09-15 17:00 | 外部系统最终使用的稳定 ID、资格资料截止与判定时点；不可把报名截止自动等同于资料截止 |
| 甲方已发布三级分类路径及版本 | 候选：`IT与通讯 → 办公设备 → 电脑(台式机/笔记本)` | 实际企业树节点 ID、名称、定义、说明及版本 |
| 知识包与本次资格条件 | [案例映射](./PRO-IT-2026-014-review.md)列出条件；经营范围是用户补充的模拟案例必须项 | 每条条件 ID、原文、判定说明、材料或声明要求、适用阶段、本体与规则版本；业务比较交 LLM |
| 本次取值 | 100 台；资本 ≥500 万；成立 ≥3 年；同类项目 ≥2 且每单 ≥50 台；上海团队 ≥5 人等 | 采购员确认的完整值；品牌、项目授权的适用对象和判定日期 |

单台 9,500 元是价格目标，30 天交货是投标评分项；两者不作为本次资格预审必须项。

## 每家乙方的已发布本体事实

每条事实均填写：**值、单位或日期、所属乙方、对应二级品类能力、确认/发布版本、来源文本或引用、适用范围与时间**。未知值留空并标明缺失，不从通过/失败结论反推。

| 事实类型 | 最小字段 | 用途 |
| --- | --- | --- |
| 分类与能力 | 已发布完整三级路径及各级定义、电脑供应能力与可供采购匹配标记；若本次新声明能力，则补临时完整路径、各级描述、声明来源与披露授权 | 先做品类候选筛选；临时能力仅用于本项目 |
| 企业资格 | 独立法人状态、注册资本金额与币种、成立日期、营业执照经营范围 | 资格必须项；经营范围是本模拟案例修订 |
| 品牌渠道 | 可供应品牌、一级代理或系统集成商身份、对应有效期 | 与本次拟投品牌及项目授权组合判断 |
| 过往案例 | 每个项目的起止时间、设备类型、单批台数、合同证据引用 | 本案例指定 2023-01 至 2026-08，至少两例、每例至少 50 台 |
| 本地服务 | 上海常驻技术人员数量、核验时间与来源 | 团队至少五人 |
| 合规与投标主体 | 重大违法/失信核查结果及时间；是否联合体、是否转包/分包的声明 | 分别核验，不能将缺记录视为通过 |

## 乙方本次逐条件声明与可选材料

对每家乙方的每项资格条件，收集其本次回答或承诺的**原话、对应条件 ID、说话人/调用身份、时间、项目范围及向甲方披露授权引用**。乙方明确声明“有”可按诚信申报用于本次预审，即使没有上传证明；不得将自述标为已核验证明。若本次声明与旧乙方本体事实相反，仍记录冲突并按本次声明判定，供案例复核和乙方待确认候选审核。

若乙方选择提供文件，对每份材料记录：`材料 ID / 文件名 / 文本内容 / 来源 / 文档版本 / 形成与适用时间 / 关联品牌和采购项目 ID / 披露授权引用`。原始 PDF、图片留在外部系统；本工程只返回有权可见的命中片段。材料可包括原厂针对本项目的授权函、案例合同关键页等；**本轮入围判定不强制上传这些原件**。

## 事先写定的预期与最小样本

每条样本在运行前填写：`采购项 ID、乙方 ID、阶段、预期四态结果、逐条件预期及理由、人工标注人和时间`。模拟复盘给出的资格预审业务预期是 8 家通过、3 家不通过；它不是完整机器输入，也不自动等于四态判定结果。

首轮最小联调建议收集 **1 家通过者 + S6（缺项目授权函）+ 新报名 A（资本及案例不足）+ 新报名 B（经营范围不符）**的乙方本体及本次逐条件声明。若要完整重放 8/3，须补齐全部 11 家的本体与本次声明或材料；若某乙方未作相关声明且本体、材料也无相关内容，截止前为`待乙方补资料`，截止后为`不满足`。**S6 若本次逐项声明“有原厂本项目授权”，即使未上传函件，也可能按新规则通过**；此时应记录与模拟复盘预期的差异，不得为了凑 8/3 把它改判失败。
