## 离线校验结果

对上述有依据的 6 项人工样本，使用实际 v2 注册绑定验证：两套 Pydantic 根模型均接受取值，归一化后产生 8 个候选对象；字段值保留，关系端点在本次样本内解析，全部摘录与字符位置通过 `SourceSpan.validate_against` 校验。用于核对的来源显式标记 `simulated=True`，候选保留 `PENDING_REVIEW`，没有发布。

这是人工样本表达检查，不是模型识别率、完整抽取率或业务专家签字验收。本轮没有改程序，未重复运行此前已通过的完整测试；既有结果见 [v2 Schema 说明](schemas/v2.md)。本地校验脚本及 JSON 回执保留于被 Git 忽略的 `.scratch/v2-business-review-20261109/`。
